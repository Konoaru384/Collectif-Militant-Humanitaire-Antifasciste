Aperçu

Les actions de l'agenda se gèrent maintenant directement sur le site, sans passer par Google Agenda ni aucune clé API : vous les ajoutez, modifiez ou retirez depuis une page dédiée, puis vous téléchargez le fichier à installer.

Ouvrir la gestion de l'agenda

Pour que l'icône et l'affichage soient corrects

Dans le titre de l'action, utilisez un des mots suivants :

  • tracts ou flyers : une distribution de tracts
  • apéro : un apéro militant
  • rencontre ou meeting : une rencontre / réunion
  • congrès : un congrès, automatiquement indiqué comme se déroulant en ligne

Dans le champ "Lieu", indiquez la ville ou l'adresse pour qu'elle apparaisse correctement sur la carte du site (ou cochez "en ligne" pour une visioconférence).

Si l'action est liée à une mobilisation sur Action Populaire, collez simplement le lien de la page Action Populaire dans le champ "Description" : il sera automatiquement détecté et affiché comme lien de participation.
